# Dockyra Feature Specifications (`planning/features/README.md`)

Feature specifications track product capabilities across their lifecycle:
- `planned/`: Approved feature designs awaiting implementation (`[FEATURE-0002-drag-and-drop-groups.md](planned/FEATURE-0002-drag-and-drop-groups.md)`).
- `active/`: Features currently under active development.
- `completed/`: Verified features running in the codebase (`[FEATURE-0001-foundation-and-prototype.md](completed/FEATURE-0001-foundation-and-prototype.md)`).
