# Dockyra Task Management (`planning/tasks/README.md`)

All development tasks in **Dockyra** carry a unique `TASK-XXXX` identifier and follow a strict lifecycle:
`BACKLOG` -> `READY` -> `IN_PROGRESS` -> `IN_REVIEW` -> `TESTING` -> `DONE` (or `BLOCKED`).

## Task Registries
- [completed.md](completed.md) — Verified and completed tasks with build/test status.
- [in-progress.md](in-progress.md) — Currently active and ready tasks.
- [backlog.md](backlog.md) — Upcoming planned tasks for future phases.
- [blocked.md](blocked.md) — Tasks awaiting external dependencies or user decisions.
