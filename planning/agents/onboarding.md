# AI Agent Onboarding Protocol (`planning/agents/onboarding.md`)

When starting a session on Dockyra:
1. Read `AGENTS.md` at the repository root.
2. Read `planning/PROJECT-OVERVIEW.md` and `planning/CURRENT-STATE.md`.
3. Inspect `planning/modules/module-registry.yaml` to map the user's request to a module (`MOD-*`).
4. Read the latest handoff in `planning/handoffs/` and active task in `planning/tasks/in-progress.md`.
5. Run `dotnet build Dockyra.sln` and `dotnet test Dockyra.sln` to confirm the workspace baseline before editing files.
