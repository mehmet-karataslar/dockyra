# Cross-Agent Handoff Protocol (`planning/agents/handoff-protocol.md`)

To allow seamless transitions between Antigravity, Claude Code, OpenAI Codex, and human engineers:
1. At the end of a major milestone or session, create or update a handoff record in `planning/handoffs/HANDOFF-YYYY-MM-DD-<slug>.md` using `planning/templates/handoff-template.md`.
2. Update the **Latest Handoff** pointer at the top of `planning/CURRENT-STATE.md`.
3. Never include unverified assumptions as completed work; list exact `dotnet build` and `dotnet test` results.
